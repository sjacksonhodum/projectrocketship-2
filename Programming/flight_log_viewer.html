How to get a dump off the rocket

  1. Easiest: click Connect to rocket (Web Serial) above, pick the rocket's USB port, and it sends DUMP and loads the result automatically. Needs Chrome or Edge, and the rocket connected directly over USB (not through the ground station). If that button is disabled or fails, your browser or this page's sandbox doesn't allow direct serial access - use the manual steps below instead. If the connection drops partway through (a flaky USB cable/port), the button relabels itself Resume dump (from byte N) - reconnect and click it again to pick up exactly where it left off instead of starting over.
  2. Manual fallback: connect the rocket directly to your computer over USB, open a serial connection at 115200 baud, and log it to a file. Easiest with PlatformIO, from the RP2040 project folder:
    pio device monitor -b 115200 --filter log2file
    (writes a timestamped .log file alongside logging to your terminal) - or use your Arduino IDE Serial Monitor and copy the output by hand.
  3. Type DUMP and press enter. The rocket prints # FLASH DUMP START, one hex line per logged packet, then # FLASH DUMP END.
  4. Load that file below, or paste the text directly. Lines that aren't packets (anything starting with #) are ignored automatically, so it's fine to paste the whole terminal capture.
